1

快速开始 — 配置 API Key

使用前需要在「通道设置」中填入 API Key，否则无法生成图片。

❶

打开通道设置

点击左侧面板的「通道设置」链接，进入设置页面。

❷

获取生图 API Key

在「生图通道」中新增或启用一个通道，填入你所用中转站/服务商分配的 API Key、Base URL 和模型名（如 GPT-Image-2、Wan 2.7 等），然后点击「保存」。

❸

（可选）配置 AI 助手模型

如需使用「一键优化提示词」功能，在「AI 助手模型」中展开某个平台卡片（DeepSeek / MiniMax / 其他服务），各平台独立填写接口地址、API Key 和模型名，然后选中「设为当前使用」并保存。填什么就是什么，模型名可自由输入。

💡 提示：API Key 会安全保存在当前浏览器中，下次打开还在。生图通道与 AI 助手模型使用独立的 API Key，可共用同一个 Key 或分开管理。“一键优化”使用哪个平台，取决于你在 AI 助手模型卡片中勾选了哪个「设为当前使用」。
2

文生图 — 用文字生成图片

最常用的模式。输入一段描述文字，AI 帮你画出对应画面。

❶

选择模型

在左侧「生成控制台」顶部，从下拉框选择已启用的生图通道模型（如 GPT-Image 中转模型、Agnes Image 等）。具体模型可在设置页通道中切换。

❷

选择比例与质量

设置图片比例（1:1 / 3:4 / 4:3 / 9:16 / 16:9 / 21:9）和清晰度（1K / 2K / 4K）。竖版内容建议选 3:4，横版选 16:9。

❸

选择风格（可选）

从「风格模板」中挑选预设风格：写实摄影、海报视觉、数字插画、水彩手绘、3D 物料、东方美学。也可以选「无」让 AI 自由发挥。

❹

输入提示词

在输入框中描述你想要的画面。越详细越好，例如：

✅ 好的例子：

一只橘猫躺在午后阳光照射的木地板上，身边散落着几本书，温馨的家庭氛围，照片级写实风格

❌ 不太好的例子：

一只猫

也可以点「随机生图」让系统自动填入一个随机提示词试试效果。

❺

开始生成

点击「开始创作」按钮，或按 Ctrl + Enter。图片会在右侧预览区显示，自动保存到本地图库。

3

批量生图 — 一次生成多张

一次性输入多段提示词，系统按顺序逐一生成，生成完一张自动接着下一张。

❶

切换到批量模式

点击模式选择中的「批量」，输入框会变成批量提示词输入框。

❷

输入多段提示词

每段提示词之间用空行分隔。例如：

一只橘猫在阳光下午睡，写实风格

一只黑猫在月光下散步，神秘氛围

一只白猫在花丛中玩耍，清新插画

❸

检查队列

下方「队列预览」会显示所有待生成的提示词列表，可以确认顺序和内容。

❹

开始批量生成

点击「开始批量」，系统会逐条生成。生成过程中可以随时点击「停止批量」终止后面的任务。

💡 提示：批量生成的每张图片都会单独显示在右侧对话区和本地图库中，每条记录独立可查。
4

模板变量 — 批量更省力

如果批量提示词都是同一个模板、只是主题不同，可以用「模板变量」功能一键展开，省去逐条复制的麻烦。

❶

写好模板

在批量输入框中写一段带 {变量名} 的模板：

一只可爱的{动物}在森林里玩耍，阳光透过树叶洒下来，水彩插画风格

❷

填变量值

在下方的变量值文本框中每行填一个值：

小猫咪

小狗狗

小兔子

❸

展开到输入框

点击「填充到输入框」，模板会自动展开成多条完整提示词，每条之间空行分隔。

❹

开始批量

检查展开后的内容，确认无误后点击「开始批量」生成。

💡 进阶：支持多个变量。模板里可以写 {人物},{场景},{动作}，变量值每行用逗号分隔不同变量，例如：小女孩,花园,荡秋千。
5

提示词库 — 收藏与复用

把日常收集到的好用提示词集中保存，生成图片时一键取用，避免每次重新编写。

📚

访问入口

在创作台顶部导航点击「提示词库」，或直接打开 prompts.html。

➕

新增提示词

点击工具栏「+ 新增提示词」，填写「短名称 / 分类 / 提示词内容」保存。分类可自由输入，便于筛选。

🔍

搜索与筛选

顶部搜索框按「名称、分类、提示词内容」模糊匹配；下方分类 chip 快速切换；点击「收藏」只看已收藏的提示词。

♥

收藏常用

卡片右上角的 ♥ 按钮可标记常用提示词，方便快速定位。

📋

复制 / 编辑 / 删除

每张卡片底部对应按钮：复制把提示词放入剪贴板；编辑可随时改写；删除前会有确认弹窗。

🔗

与创作台联动

创作台对话中可点「收藏提示词」把当前 prompt 加入收藏夹；提示词库里的「复制」按钮，复制的内容可直接粘贴回创作台输入框。

导出 / 导入（跨电脑迁移）

提示词库数据保存在浏览器的 localStorage 中，不会随项目文件夹一起复制。换电脑、换浏览器、换访问端口后数据不会自动跟随，需要手动迁移。

❶

在旧电脑导出

打开提示词库页，点击工具栏右侧的「导出」按钮。浏览器会自动下载一个 prompt-library-YYYYMMDD-HHmm.json 文件，妥善保存（可放进项目文件夹随 U 盘带走，或网盘备份）。

❷

拷贝到新电脑

把导出的 JSON 文件拷贝到新电脑任意位置。

❸

在新电脑导入

在新电脑上打开提示词库页，点击「导入」按钮，选择刚才的 JSON 文件。弹出确认框：

  • 确定 = 合并模式：保留当前库，按 ID 覆盖重复项，新增追加在前面（推荐日常迁移用）
  • 取消 = 替换模式：清空当前库再导入（适合在新电脑首次搭建使用）

完成后会提示「新增 / 更新」数量，列表自动刷新。

💡 提示：导入只作用于当前浏览器 + 当前访问地址（http://127.0.0.1:3211）。如需同步到无痕窗口或别的浏览器，每个上下文都要单独导入一次。账号、API Key 等私密信息不会被一起导出，迁移提示词库是安全的。
6

图片库与记录管理

所有生成的图片都会保存在本地，随时回顾和管理。

🖼️

本地图片库

点击左侧「打开本地图片库」进入画廊页面。所有生成图片按日期排列，支持按比例筛选、放大预览、下载和批量删除。

📝

最近创作

左侧底部「最近创作」面板列出当前对话的生成记录，方便快速复用之前的提示词。

🗑️

清空记录

点击「清空对话」可清空当前对话记录但保留图库；「清空记录」清空所有记录。图片库中的图片需手动删除。

📥

下载图片

在右侧对话区点击图片可放大预览；在图片库中每张卡片下方都有「下载」按钮。

💡 提示：所有图片保存在项目目录下的 generated-images/ 文件夹中，按日期分目录存放。整个文件夹可随意拷贝到其他电脑使用。
