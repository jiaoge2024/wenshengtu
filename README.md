# 图生图长 · AI创作台独立版

双击 `start.bat` 启动，浏览器会打开：

```text
http://127.0.0.1:3211/
```

生成后的图片会自动保存到本文件夹内的：

```text
generated-images/
```

如果要移动到别的电脑或别的目录，直接移动整个 `image-studio-standalone` 文件夹即可。

## 核心功能

- **文生图**：输入文字描述，AI 生成对应图片，可选比例、清晰度与风格模板。
- **批量生图**：一次输入多段提示词（空行分隔），系统逐条生成。
- **模板变量**：批量提示词套用 `{变量}` 模板，一键展开多条。
- **随机生图**：内置 30 条示例提示词，一键自动填充。
- **一键优化提示词**：用 AI 助手模型把提示词优化得更详细（需配置 AI 助手模型）。
- **生图通道**：动态管理多个生图 API（OpenAI Images 兼容 / Agnes），每个通道独立配置接口地址、API Key、模型。
- **AI 助手模型**：独立配置多个文字 AI 平台（DeepSeek / MiniMax / 其他服务），每个平台各自的 URL、API Key、模型，勾选「设为当前使用」切换一键优化所用平台。
- **提示词库**：收藏与复用常用提示词，支持搜索、分类、导入导出。
- **本地图片库**：所有生成图片按日期保存，可预览、下载、删除。

## 快速开始

1. 打开「通道设置」。
2. 在「生图通道」中新增或启用一个通道，填入 API Key、Base URL 和模型名，点击「保存」。
3. （可选）在「AI 助手模型」中配置文字 AI 平台，用于「一键优化提示词」。

## 提示词库

提示词库是本工具的「生图提示词收藏夹」，用于把日常收集到的好用提示词集中保存起来，生成图片时可以一键取用，避免每次重新编写。

### 访问入口

在创作台顶部导航点击「提示词库」，或直接打开：

```text
http://127.0.0.1:3211/prompts.html
```

### 主要功能

- **新增提示词**：点击工具栏右侧「+ 新增提示词」，填写「短名称 / 分类 / 提示词内容」即可保存。分类可以自由输入，便于以后筛选。
- **搜索**：工具栏左侧搜索框支持按「名称、分类、提示词内容」模糊匹配，输入即筛。
- **分类筛选**：搜索框下方的分类 chip 可快速切换；点击「全部」查看全部，点击「收藏」只看已收藏的。
- **收藏**：卡片右上角的 ♥ 按钮可标记常用提示词，方便快速定位。
- **复制 / 编辑 / 删除**：每张卡片底部都有对应按钮，复制可一键把提示词内容放到剪贴板；编辑可随时改写；删除前会有确认弹窗。
- **导入 / 导出**：用于跨电脑迁移提示词库，详见下文「提示词库导入 / 导出」章节。

### 与创作台联动

- 在创作台生成图片的对话中点「收藏提示词」，可把当前 prompt 直接加入收藏夹。
- 提示词库里的「复制」按钮，复制的内容会带上完整的提示词正文，可直接粘贴回创作台输入框。

### 数据存储

- 提示词库数据保存在浏览器 `localStorage` 中，**不会**写入项目文件夹。换电脑、换浏览器、换访问端口后数据不会自动跟随。
- 想随身带走请使用下面的「导出」功能，详见下一章节。

## 数据存储位置

- **生成图片**：保存到 `generated-images/` 目录，复制文件夹即可随身带走。
- **提示词库 / 账号 / 历史记录 / 模型参数等**：保存在浏览器的 `localStorage` 里，**不会**写入项目文件夹。换电脑、换浏览器、或换访问端口后，原数据不会自动跟着走。

> 提示词库的存储 key 为 `jiaoge-ai-toolbox:prompt-library-v1`，可以在浏览器 DevTools → Application → Local Storage 中查看。

## 提示词库导入 / 导出

为方便跨电脑迁移，提示词库页（`prompts.html`）工具栏新增了「导出 / 导入」两个按钮。

### 导出（在旧电脑上操作）

1. 打开提示词库页 `http://127.0.0.1:3211/prompts.html`
2. 点击工具栏右侧的 **「导出」** 按钮
3. 浏览器会自动下载一个 `prompt-library-YYYYMMDD-HHmm.json` 文件，妥善保存（可放进项目文件夹随 U 盘带走，或网盘备份）

### 导入（在新电脑上操作）

1. 把上面导出的 JSON 文件拷贝到新电脑任意位置
2. 在新电脑上打开提示词库页 `http://127.0.0.1:3211/prompts.html`
3. 点击工具栏右侧的 **「导入」** 按钮，选择之前导出的 JSON 文件
4. 弹出确认框：
   - **确定** = 合并模式：保留当前库，按 ID 覆盖重复项，新增追加在前面（推荐日常迁移用）
   - **取消** = 替换模式：清空当前库再导入（适合在新电脑首次搭建使用）
5. 导入完成后会提示新增/更新数量，列表自动刷新

### 注意事项

- 导入文件必须是上面「导出」按钮生成（或结构兼容）的 JSON；其它来源请先用本工具导出一份样例作为参照。
- 导入仅作用于当前浏览器 + 当前访问地址（`http://127.0.0.1:3211`）。如果想同步到无痕窗口或别的浏览器，每个上下文都需要单独导入一次。
- 账号、模型密钥等私密信息**不会被一起导出**，迁移提示词库是安全的。
