# 图生图长 · AI 创作台（独立版）

> 一个开箱即用的本地 AI 文字生图工具，支持多通道、多平台、多模板。

---

## 📖 项目简介

图生图长 AI 创作台是一款**纯本地运行的 Web 工具**，无需注册、无需云端账号，只需一个生图 API Key 即可在浏览器中完成所有创作。

它把日常生图中最高频的几件事——**文生图、批量生图、模板变量、随机灵感、提示词收藏、本地图库管理**——整合进同一个界面，并支持**多通道动态切换**与**多 AI 助手平台**。

适合：

- 🎨 自媒体 / 设计师需要批量出图
- 🧪 测试不同生图模型、中转 API 的效果
- 📚 长期积累常用提示词的个人素材库
- 🪟 需要离线工具、便携拷贝使用的场景

## 🚀 快速开始（3 分钟上手）

### 第一步：启动

双击项目根目录下的 `start.bat`，浏览器会自动打开：

```
http://127.0.0.1:3211/
```

> 也可以在终端运行 `node server.js` 手动启动。

### 第二步：配置生图 API

点击左侧「**通道设置**」→ 切到「**生图通道**」：

1. 新增或启用一个通道
2. 填写 **Base URL**、**API Key**、**模型名**
3. 点击「保存」

> 模型名、URL 取决于你用的中转服务或官方接口（如 `https://api.openai.com`、`https://api.apimart.ai` 等），填什么就是什么。

### 第三步：（可选）配置 AI 助手模型

如果想用「一键优化提示词」功能，配置文字 AI：

1. 在设置页切到「**AI 助手模型**」
2. 展开某个平台卡片（DeepSeek / MiniMax / 其他服务）
3. 填入该平台的 **接口地址 / API Key / 模型名**
4. 勾选「**设为当前使用**」并保存

### 第四步：开始创作

回到创作台，输入提示词 → 点击「**开始创作**」（快捷键 <kbd>Ctrl</kbd> + <kbd>Enter</kbd>）。

🎉 搞定。

## ✨ 核心功能

### 1️⃣ 文生图（基础）

输入文字描述，AI 生成对应图片。支持：

- **比例**：1:1 / 3:4 / 4:3 / 9:16 / 16:9 / 21:9
- **清晰度**：1K 标准 / 2K 高清 / 4K 超清
- **风格模板**：写实摄影 · 海报视觉 · 数字插画 · 水彩手绘 · 3D 物料 · 东方美学
- **批量张数**：单次生成 1～4 张

### 2️⃣ 批量生图

把多段提示词（用**空行分隔**）一次性粘贴到批量输入框，系统会**逐条顺序生成**，每条独立保存为一张图，生成过程可随时「停止」。

### 3️⃣ 模板变量

如果一批图的提示词是同一个模板、只换主题，可用 `{变量}` 模板 + 变量值表快速展开：

```
模板：一只{动物}在{场景}里{动作}

变量值：
橘猫,阳光房,睡觉
黑猫,月光下,散步
白猫,花丛中,嬉戏
```

点击「填充到输入框」→ 一键展开为多条完整提示词 → 进入批量生图。

支持**多变量**（用逗号分隔）；变量值不足时按顺序补空。

### 4️⃣ 随机生图

内置 **30 条**精选示例提示词，一键随机填入输入框，适合快速试模型 / 找灵感。

### 5️⃣ 一键优化提示词

选中文本后点击「**一键优化**」，工具会调用你在「AI 助手模型」中设为当前使用的平台，把你的简短描述改写成更详细、效果更好的英文 prompt，再自动填回输入框。

> 已对 MiniMax 等带「思考过程」的模型做了结果清洗，确保返回的是干净提示词。

### 6️⃣ 多生图通道管理

支持**任意多个**生图 API 通道，每个通道独立配置：

| 字段 | 说明 |
|------|------|
| 通道名称 | 自定义，仅用于显示 |
| 接口类型 | `OpenAI Images 兼容` / `Agnes Images` |
| 出图模式 | `自动检测` / `同步出图` / `异步出图` |
| Base URL | 服务商接口根地址，如 `https://api.openai.com` |
| API Key | 该服务商分配的密钥 |
| 模型名 | 该服务商提供的具体模型 ID |

所有已启用通道的模型会自动出现在创作台的「生图模型」下拉框中，随时切换。

### 7️⃣ 多 AI 助手平台

AI 助手模型分为三张**完全独立**的卡片（DeepSeek / MiniMax / 其他服务），每张卡片各自一套：

- **接口地址**（Base URL）
- **API Key**
- **模型名**

通过「**设为当前使用**」单选按钮决定一键优化走哪个平台，配置不会相互覆盖。

### 8️⃣ 提示词库

独立的提示词收藏页面：

- 📝 新增 / 编辑 / 删除
- 🔍 模糊搜索（按名称、分类、内容）
- 🏷️ 分类 chip 筛选
- ♥ 收藏常用
- 🔗 与创作台双向联动：创作台生成图后可「收藏提示词」一键入库；从库中「复制」可一键粘贴回输入框
- 📤📥 **导入 / 导出** JSON，跨电脑迁移

### 9️⃣ 本地图片库

所有生成图片按日期保存在项目内 `generated-images/` 目录中，独立图片库页面支持：

- 按日期浏览、缩略图预览
- 🔎 按比例筛选
- 🔍 单图放大预览
- ⬇️ 单张下载
- 🗑️ 批量删除

### 🔟 账号系统（可选）

工具内置轻量账号系统，注册 / 登录后可保留个性化配置（默认模型、API Key 等）。账号数据保存在本地 `localStorage`，**不会上传到任何服务器**。不需要账号也能使用全部生图功能。

## ⚙️ 配置详解

### 生图通道（设置页 → 生图通道）

#### 接口类型说明

- **OpenAI Images 兼容**：适用于任何兼容 `/v1/images/generations` 接口的服务商，包括 OpenAI 官方、各种中转、自建网关。
- **Agnes Images**：Agnes Image 专用接口，地址一般为 `https://apihub.agnes-ai.com/v2`。

#### 出图模式说明

- **自动检测（推荐）**：根据服务商返回判断走同步或异步流程，**大多数情况下无需改动**。
- **同步出图**：接口直接返回图片 URL，常见于 OpenAI 官方及大部分中转。
- **异步出图**：接口先返回任务 ID，工具会轮询查询直到图片生成完成，常见于 Agnes。

#### 常见 Base URL 示例

| 服务 | URL |
|------|------|
| OpenAI 官方 | `https://api.openai.com/v1` |
| APIMart 中转 | `https://api.apimart.ai/v1` |
| Agnes Image | `https://apihub.agnes-ai.com/v2` |
| 自建 / 其他中转 | 你的服务商提供的根地址 |

#### 测试通道

填写完成后点击卡片右上「**测试**」按钮，工具会发一次最小请求验证 API Key 与模型是否可用。测试结果会即时显示。

### AI 助手模型（设置页 → AI 助手模型）

三张卡片相互独立：

| 平台 | 默认 Base URL | 说明 |
|------|--------------|------|
| DeepSeek | `https://api.deepseek.com/v1` | 国产，OpenAI 兼容格式 |
| MiniMax | `https://api.MiniMax.chat/v1` | 国产，OpenAI 兼容格式 |
| 其他服务 | （空） | 用于任意 OpenAI 兼容 LLM |

模型名示例：

- DeepSeek：`deepseek-chat`、`deepseek-reasoner`
- MiniMax：`MiniMax-Text-01`、`MiniMax-M1`
- 其他：服务商提供的具体模型 ID

只需在每张卡片中填好你想用的那一项，其余留空也互不影响。

## 📂 数据存储位置

```
image-studio-standalone/
├─ start.bat                ← 启动脚本
├─ server.js                ← 本地服务器
├─ index.html               ← 创作台
├─ settings.html            ← 通道设置
├─ prompts.html             ← 提示词库
├─ gallery.html             ← 本地图片库
├─ help.html                ← 浏览器内使用说明
├─ *.js / *.css             ← 应用代码
├─ generated-images/        ← 生成图片（自动创建）
└─ tests/                   ← 测试用例
```

| 数据 | 位置 | 跟随文件夹移动？ |
|------|------|------------------|
| **生成图片** | `generated-images/` 文件夹 | ✅ 是 |
| **提示词库** | 浏览器 `localStorage` | ❌ 否（需手动导出） |
| **账号 / 历史 / 模型参数 / API Key** | 浏览器 `localStorage` | ❌ 否 |
| **测试用例 / 代码** | 项目文件夹 | ✅ 是 |

> 整个 `image-studio-standalone` 文件夹可直接拷贝到其他电脑使用，但浏览器 `localStorage` 不会跟着走。如果想保留提示词库，**记得用提示词库的「导出」功能**。

## 📤 提示词库导入 / 导出

> 提示词库存储 key：`jiaoge-ai-toolbox:prompt-library-v1`
> 可在浏览器 DevTools → Application → Local Storage 中查看。

### 导出（旧电脑）

1. 打开 `http://127.0.0.1:3211/prompts.html`
2. 点击工具栏「**导出**」按钮
3. 浏览器自动下载 `prompt-library-YYYYMMDD-HHmm.json`，妥善保存

### 导入（新电脑）

1. 拷贝上面的 JSON 文件到新电脑
2. 打开提示词库页
3. 点击「**导入**」，选择 JSON 文件
4. 弹窗确认模式：
   - **确定** = 合并模式（保留现有，按 ID 覆盖重复项，新增追加前面）→ 推荐日常迁移
   - **取消** = 替换模式（清空当前库再导入）→ 适合新电脑首次搭建

### 注意事项

- 仅接受本工具「导出」生成（或结构兼容）的 JSON
- 导入仅作用于**当前浏览器 + 当前访问地址**；无痕窗口或别的浏览器每个都要单独导入
- API Key、账号密码**不会被一起导出**，迁移安全

## 🛠️ 故障排查

| 现象 | 原因与处理 |
|------|-----------|
| 点击「开始创作」报错「请先填写 API Key」 | 进入「通道设置」→ 生图通道 → 填入 API Key 并保存 |
| 一键优化失败 | 进入「通道设置」→ AI 助手模型 → 检查是否已勾选「设为当前使用」，并填好 API Key |
| 测试通道失败 | 检查 Base URL 是否带 `/v1` 后缀、模型名是否拼写正确、API Key 是否过期 |
| 端口 3211 被占用 | 编辑 `server.js` 顶部的 `PORT = 3211` 改成其他端口，再重启 |
| 图片未保存到本地 | 检查浏览器是否允许下载，确认 `generated-images/` 目录可写 |
| 想清空所有设置 | 设置页底部「**清空所有设置**」按钮（不可恢复，建议先导出提示词库） |

## 📝 开发者备注

- 纯前端 + 本地 Node 服务器，**无任何后端依赖**
- 所有 API 调用由浏览器发出（少数情况下经 `proxyFetch` 走本地代理绕开 CORS）
- 浏览器 `localStorage` 是唯一本地数据源，请定期导出重要数据
- 代码模块：`app.js`（主逻辑）· `app-utils.js`（工具）· `app-config.js`（常量与默认值）· `settings.js`（设置页）· `gallery.js`（图片库）· `prompts.js`（提示词库）· `server.js`（本地服务器）

## ❓ 常见问题

**Q：可以不用账号吗？**
A：可以。账号系统仅用于在本地保存个性化配置，不影响任何核心功能。

**Q：生成的图片会丢失吗？**
A：图片直接写入 `generated-images/` 目录，与项目共存亡；提示词库等数据则在浏览器 localStorage 中，建议导出备份。

**Q：能换 OpenAI 官方以外的模型吗？**
A：可以。「生图通道」支持任意兼容 OpenAI Images 接口的服务商，URL 与模型名自由填写。

**Q：可以同时用多个模型对比效果吗？**
A：可以。给同一个提示词生成完后，切换模型再生成一次，两张图都会保留在图片库和对话区。

**Q：本地数据安全吗？**
A：所有数据都保存在你自己电脑上，不上传任何服务器。迁移时建议手动导出提示词库。
